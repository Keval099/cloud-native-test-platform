# Cloud-Native Test Automation & Deployment Platform

## Overview

A production-style cloud-native application demonstrating:

- Java Spring Boot
- PostgreSQL
- REST API automation
- Docker
- GitHub Actions
- Amazon ECR
- Amazon EKS
- Terraform

- AWS VPC
- AWS RDS
- AWS ALB
- AWS Secrets Manager
- CloudWatch
- Prometheus
- Grafana
